# QEMU Admin — Vault

Gerenciador local de VMs QEMU em Elixir/Phoenix LiveView, com a tela de cada VM dentro do app (noVNC) e empacotamento desktop via Tauri. O README do repositório (na raiz) tem o guia de uso completo.
